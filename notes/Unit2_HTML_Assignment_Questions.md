# Unit II: HTML Fundamentals — Assignment Questions

1. **Create a Simple Heading** — Create an HTML page with a main heading.
2. **Create a Paragraph with a Link** — Create a paragraph of text that contains a hyperlink within it.
3. **Create a Tooltip on Hover** — Create an element that shows a tooltip (extra text) when the user hovers over it.
4. **Create a Button** — Create a clickable button on the page.
5. **Create an Unordered List** — Create a bulleted list of at least three items.
6. **Create a Simple Table** — Create a table with a header row and at least two data rows.
7. **Create a Form with Input Fields** — Create a form collecting a user's name and email.
8. **Create a Form with a Dropdown Menu** — Create a form with a dropdown (select) menu offering multiple choices.
9. **Create an Image with Alt Text** — Add an image to the page with appropriate alternative text.
10. **Create a Hyperlink that Opens in a New Tab** — Create a link that opens in a new browser tab when clicked.
11. **Create a Progress Bar** — Display a progress bar showing partial completion of a task.
