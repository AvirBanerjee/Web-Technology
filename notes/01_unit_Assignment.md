# Unit I: How the Web Works — Assignment

**Instructions**: Answer all 10 questions. Questions marked "Practical" require you to use browser DevTools.

---

**Q1.** Differentiate between the Internet and the Web. List two services (other than the Web) that also run on the Internet.

**Q2.** Explain the client-server model with the help of a labelled diagram. Identify which side (client or server) initiates communication, and which side responds.

**Q3.** Break down the following URL into its components (scheme, host, port, path, query string, fragment) and explain the purpose of each part:
```
https://www.shopease.com:443/products/laptops?brand=dell&sort=price#reviews
```

**Q4.** List any five HTTP methods and explain the purpose of each with one real-world example for each.

**Q5.** Explain the difference between a GET request and a POST request. Give one scenario where GET should be used and one scenario where POST must be used, with justification.

**Q6.** Explain what each of the following HTTP status codes means, and give one situation in which a browser would receive it: `200`, `301`, `404`, `401`, `500`.

**Q7.** Explain, step by step, what happens between typing `www.myexample.com` in the browser's address bar and the IP address being resolved. Include all the stages a DNS lookup passes through.

**Q8.** List and explain any four types of DNS records (for example, A, AAAA, CNAME, MX) and state what each one is used for.

**Q9.** Explain the browser rendering pipeline (DOM, CSSOM, Render Tree, Layout, Paint, Composite) using a diagram. Why is it recommended to place `<script>` tags at the end of `<body>` or use the `defer` attribute, based on this pipeline?

**Q10 (Practical).** Open any three real-world websites (for example, Amazon, Wikipedia, YouTube). Using the Network tab in DevTools, inspect the very first HTTP request for each website and note down:
- Request method
- Status code
- Content type
- Response size
- Any redirects observed

Submit a short table summarizing your findings for all three websites.
