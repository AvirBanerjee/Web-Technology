# Questions on Loops

<details>
<summary>1. Print Numbers 1 to N
</summary>
Problem: Given a number N, print all numbers from 1 to N, one per line, using a for loop.

</details>

<details>
<summary>2. Print Numbers in Reverse
</summary>
Problem: Given a number N, print all numbers from N down to 1 using a while loop.

</details>

<details>
<summary>3. Sum of First N Numbers
</summary>
Problem: Calculate and print the sum of all numbers from 1 to N.
(e.g., N = 5 - 1 + 2 + 3 + 4 + 5 = 15)

</details>

<details>
<summary>4. Multiplication Table
</summary>
Problem: Given a number, print its multiplication table from 1 to 10 in the format "5 x 3 = 15".

</details>

<details>
<summary>5. Even and Odd Numbers
</summary>
Problem: Print all even numbers and, separately, all odd numbers between 1 and 50.

</details>

<details>
<summary>6. Factorial
</summary>
Problem: Calculate the factorial of a number N using a loop.
(e.g., 5! = 5 x 4 x 3 x 2 x 1 = 120)

</details>

<details>
<summary>7. Count the Digits
</summary>
Problem: Given a positive integer, count how many digits it has using a while loop (without converting it to a string).
(e.g., 45821 - 5 digits)

</details>

<details>
<summary>8. Sum of Digits
</summary>
Problem: Given a positive integer, find the sum of its digits using a while loop with % and Math.floor().
(e.g., 1234 - 1 + 2 + 3 + 4 = 10)

</details>

<details>
<summary>9. Reverse a Number
</summary>
Problem: Reverse the digits of a given positive integer using a loop.
(e.g., 12345 - 54321)

</details>

<details>
<summary>10. Palindrome Number
</summary>
Problem: Check whether a given number is a palindrome (reads the same forwards and backwards), using a loop to reverse it first.
(e.g., 121 - Palindrome, 123 - Not a palindrome)

</details>

<details>
<summary>11. Prime Number Checker
</summary>
Problem: Check whether a given number is prime. Use a loop with break as soon as a divisor is found.
(e.g., 17 - Prime, 21 - Not prime)

</details>

<details>
<summary>12. Fibonacci Series
</summary>
Problem: Print the first N numbers of the Fibonacci series, where each number is the sum of the previous two.
(e.g., N = 8 - 0, 1, 1, 2, 3, 5, 8, 13)

</details>

<details>
<summary>13. Count Vowels in a String
</summary>
Problem: Given a string, count the number of vowels (a, e, i, o, u, in both cases) using a for...of loop.
(e.g., "Hello World" - 3 vowels)

</details>

<details>
<summary>14. Reverse a String
</summary>
Problem: Reverse a given string using a loop, without using the reverse() method.
(e.g., "JavaScript" - "tpircSavaJ")

</details>

<details>
<summary>15. Largest and Smallest in an Array
</summary>
Problem: Given an array of numbers, find the largest and the smallest value using a loop, without using Math.max() or Math.min().
(e.g., [45, 12, 89, 3, 67] - Largest: 89, Smallest: 3)

</details>

<details>
<summary>16. Average and Pass Count
</summary>
Problem: Given an array of student marks, use a for...of loop to calculate the average marks and count how many students scored 40 or above.
(e.g., [78, 35, 92, 40, 28] - Average: 54.6, Passed: 3)

</details>

<details>
<summary>17. Print Object Properties
</summary>
Problem: Given the object { name: "Ravi", age: 19, course: "Web Development", city: "Bhilai" }, use a for...in loop to print every key and value in the format "name: Ravi".

</details>

<details>
<summary>18. Skip and Stop
</summary>
Problem: Loop from 1 to 20. Skip multiples of 3 using continue, and stop the loop completely when the number reaches 14 using break. Print every other number.

</details>

<details>
<summary>19. Menu Until Exit
</summary>
Problem: Using a do...while loop, keep asking the user to enter a number with prompt(). Add each number to a running total, and stop when the user enters 0. Print the final total.

</details>

<details>
<summary>20. Number Patterns
</summary>
Problem: Using nested loops, print the following patterns for N = 5:

Pattern A (right triangle of stars):
```
*
**
***
****
*****
```

Pattern B (number pyramid):
```
1
12
123
1234
12345
```

Pattern C (inverted triangle):
```
*****
****
***
**
*
```

</details>
